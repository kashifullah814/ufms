# UFMS – Test Cases

University Finance Management System (UFMS), University of Science & Technology Bannu – Final Year Project.

- **Date of testing:** 06 October 2026 (re-run after the final quality pass)
- **Version tested:** commit `2ff14b7` on PHP 8.0.30 and MariaDB 10.4.32 (XAMPP, Ubuntu)
- **Test data:** a scratch copy of the database with the demo data for fiscal year 2026-27 (60 students, 15 staff). The real database was not changed.
- **Method:** every test was run automatically. The test script sends the same requests as the browser forms, logged in as the role named in the test, and then checks the page and the database. The "Actual result" column is what the system returned in that run.
- Amounts are in PKR. Text in quotes is the message the system showed.
